# 搬砖收入桌面小组件

仿 Momoyu Pro 侧边栏卡片风格的 Windows 桌面小组件：悬浮显示**今日搬砖收入**、**发薪倒计时**、**搬砖进度条**与**状态文字**；
开启「偷偷摸摸」后整套文案切换为**学习风格**（今日学习进度 · 学习中 · 距月考还有）；窗口可拖动边缘**自由缩放**。

自带一个**内置后台**，以程序自身的窗口打开，改参数保存后小组件会立刻跟着变，无需重启。
收入计算、状态文字、偷偷摸摸开关等核心参数统一放在后台设置；小组件偏好窗口只保留数据源、刷新间隔、置顶与透明度等独立设置，避免重复。

## 快速开始

1. 双击 `dist/bzwidget.exe`（免安装单文件版）
2. 小组件出现在桌面右下角，置顶显示
3. 右键小组件 → **后台设置**（或右键托盘图标 → 打开后台设置）
4. 在后台窗口里填「月薪 / 月工作天数 / 上班时刻 / 下班时刻 / 午休时间 / 每月发薪日」等，点**保存并推送**
   - 上班、下班、午休时刻均为 **24 小时制**（`08:00`、`18:00`，支持分钟如 `09:30`）
   - 午休留空 = 不扣午休
5. 今日收入从上班时刻起**按秒累计**，**午休期间暂停跳动**，到下班时刻封顶；进度条随今日已计薪工时增长；小组件每秒自动刷新
6. 拖动窗口**边缘 / 右下角**即可自由缩放窗口，尺寸自动记住（最小 200×170）
7. 「偷偷摸摸」区块点**开启** → 文案立刻切成学习风格，点**关闭**恢复搬砖风格

## 内置后台

后台界面由程序内置的一个本地 HTTP 服务（`127.0.0.1:3456`，端口被占用会自动顺延）渲染，但**以程序窗口打开，不会调起浏览器**：

| 地址 | 用途 |
| --- | --- |
| `http://127.0.0.1:3456/` | 后台设置页（在程序窗口内显示） |
| `http://127.0.0.1:3456/api/today` | 小组件读取的数据接口 |

如需在浏览器里访问，手动打开上表地址同样可用。

接口返回（收入与进度为**实时计算**的结果，并非写死的值）：

```json
{
  "income": 156.86,
  "progress": 58.82,
  "stealthMode": true,
  "status": "搬砖中",
  "studyStatus": "学习中",
  "titleMoyu": "今日搬砖收入",
  "titleStudy": "今日学习进度",
  "paydayDay": 20,
  "monthlySalary": 6400,
  "workDaysPerMonth": 24,
  "workStartTime": "08:30",
  "workEndTime": "18:00",
  "breakStartTime": "12:00",
  "breakEndTime": "13:00",
  "breakHours": 1,
  "spanHours": 9.5,
  "dailyHours": 8.5,
  "hourlyRate": 31.37,
  "perSecond": 0.008715
}
```

收入 / 进度按以下公式随当前时间动态计算，每秒刷新一次：

```
每天计薪工时 = 下班时刻 − 上班时刻 − 午休时长        （午休留空则为 0）
每秒收入    = 月薪 ÷ 月工作天数 ÷ (每天计薪工时 × 3600)
今日已工作秒数 = clamp(现在 − 今日上班时刻, 0, 在岗时长)
                − 今天已经过去的午休时长
今日收入    = 每秒收入 × 今日已工作秒数
进度(%)     = 今日已工作秒数 ÷ (每天计薪工时 × 3600) × 100
```

> 午休必须完整落在上班~下班区间内才会生效（否则视为无效并忽略），避免把工时算成负数。
> 示例：08:30–18:00、午休 12:00–13:00、月薪 6400、月工作 24 天 → 计薪工时 8.5h、时薪 ¥31.37；
> 12:30 与 13:00 的收入相同（午休期间不增长），18:00 封顶 ¥266.67。

倒计时按「每月几号」(`paydayDay`，1-31) 计算下一次发薪日 / 月考日：本月已过则顺延到下月，遇到小月自动取当月最后一天。

`POST /api/update` 可写入参数（后台页就是这么做的），保存时会立即推送刷新事件给小组件，不必等轮询。

## 偷偷摸摸（学习风格）

后台设置里的「偷偷摸摸」是一个**一键换文案**开关，开启后界面不再出现“搬砖”字样：

| 位置 | 关闭（搬砖） | 开启（学习） |
| --- | --- | --- |
| 卡片标题 | 今日搬砖收入 | 今日学习进度 |
| 主数字 | ¥156.86 | 156.86 分 |
| 倒计时 | 距发薪还有 8 天 4 小时 | 距月考还有 8 天 4 小时 |
| 状态文字 | 搬砖中 | 学习中 |
| 后台页标题 | 搬砖收入 · 后台设置 | 学习进度 · 后台设置 |
| 托盘提示 / 托盘菜单 | 搬砖收入小组件 / 打开后台设置 | 学习进度小组件 / 打开学习设置 |

两套状态文字可分别配置（`status` / `studyStatus`）；两套卡片标题也可分别配置（`titleMoyu` / `titleStudy`）。
「每月发薪日」在学习风格下即“月考日”（同一个 `paydayDay`）。
开关**即时生效**：点一下立即写入配置并推送刷新，不需要再点保存。接口字段为 `stealthMode`（布尔）。

## 开发与打包

```bash
# 开发运行
node run.js

# 打包便携版 exe（产物：dist/bzwidget.exe）
node build.js
```

打包脚本已内置 npmmirror 镜像，避免 Electron 二进制从 GitHub 下载失败。

## 接入自己的数据源

小组件不限定数据来源，任何返回上述 JSON 结构的接口都能用：

1. 右键小组件 → 小组件偏好
2. 「数据来源」选 **内置后台 / API 接口**
3. 填入你的接口地址；若是需要登录的私有接口，把 `Cookie` / `Authorization` 按 JSON 填进请求头：

```json
{ "Cookie": "session=xxx; token=yyy" }
```

4. 请求由主进程发出，不受浏览器 CORS 限制
5. 刷新间隔默认 10 秒，可调（最小 2 秒）

字段名兼容别名：`todayIncome` / `amount`、`percent` / `percentage`、`state` / `text`、`salaryDate` / `payday`。旧版的 `workStartHour` / `workEndHour`（十进制小时）与 `paydayDate`（完整日期）会在读取配置时自动迁移。

> 说明：`pro.momoyu.cc` 本身是登录后才可用的 SPA，首页是营销落地页。要抓它的真实数据，需要登录后从 DevTools → Network 里找到对应接口，把 URL 与 Cookie 填进设置。

## 配置与日志

- 配置：`~/.momoyu-widget/config.json`（窗口位置、数据源、接口、刷新间隔）
- 启动日志：`~/.momoyu-widget/startup.log`（排查「双击没反应」时看这里）

## 常见问题

**双击后没看到小组件？**
先看 `~/.momoyu-widget/startup.log` 有没有 `ready-to-show`。若窗口在屏幕外，删掉 `config.json` 里的 `x` / `y` 再启动即可回到默认位置。

**后台页打不开？**
确认小组件进程在运行（托盘有图标）。端口被占用时程序会自动换端口，右键托盘 → 打开后台设置即可。若想用浏览器访问，打开 `http://127.0.0.1:3456/`。
